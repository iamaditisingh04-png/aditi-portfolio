# Aditi Singh — Personal Portfolio

A personal portfolio built to feel like a little world of its own: a cozy, cottage-inspired environment with a scroll-driven 3D journey, playful details, and a collection of things I'm learning and building.

**Live Site:**https://aditi-portfolio-tau-silk.vercel.app/
## ✨ Features

- 3D cottage-inspired world with a scroll-driven camera journey
- Portfolio sections for About, Skills, Projects, Achievements, Coding Activity, and Contact
- Illustrated character with a subtle floating animation
- Cursor-tracking frog companion with playful click responses
- Coding activity section for GitHub, LeetCode, and CodeChef
- Responsive layout with a dark forest-inspired colour palette

## 🛠️ Built With

- React 18
- TypeScript
- Vite
- Three.js
- React Three Fiber and Drei
- GSAP and ScrollTrigger
- Tailwind CSS

## 🚀 Run Locally

### Prerequisites

- Node.js
- npm

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/iamaditisingh04-png/aditi-portfolio.git
   ```

2. Enter the project directory:

   ```bash
   cd aditi-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Create a production build:

   ```bash
   npm run build
   ```
